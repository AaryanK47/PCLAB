# C Programs

This repository contains C programs.

## How to Compile and Run

To execute a C program, open the terminal and navigate to the directory containing the `.c` file.

### Compile

Use the following general command:

```bash
gcc -fopenmp <filename>.c -o <program_name>
./<program_name>
```

EXAMPLE FOR RUNNING 1ST PROGRAM :-

```bash
gcc -fopenmp p1.c -o p1
./p1
```
